# FIX

**FIX** es una plataforma local para conectar a las personas de Huehuetenango, Guatemala, con profesionales y negocios de servicios.

## Visión

Encontrar a un profesional confiable y contactar por WhatsApp o llamada de manera sencilla. El cliente puede buscar sin registrarse. Los profesionales pueden construir una presencia digital y administrar su perfil.

## Principios del producto
- **Ámbito:** Huehuetenango, Guatemala. No se presenta como plataforma mundial.
- **Marca:** escribir **FIX**, nunca agregar un punto decorativo al logotipo.
- **Descubrimiento:** búsqueda por profesión, especialidad y municipio, con ubicación opcional y consentimiento.
- **Profesionales:** cuenta real, fotografía, una o más profesiones, portafolio, WhatsApp, horario, cobertura territorial y dirección del taller solo si desean publicarla.
- **Privacidad:** ubicación precisa privada por defecto; no exponer domicilios particulares.
- **Contacto:** dirigir a WhatsApp o llamada; FIX no procesa pagos ni reservas en su primera etapa.
- **Confianza:** verificación y reseñas solo cuando exista un mecanismo que las respalde, sin inventar calificaciones ni identidades.
- **Diseño:** móvil primero, interfaces limpias, lenguaje claro y accesible.

## Estado actual

**Planificación e infraestructura inicial.** Las pantallas previamente diseñadas son **prototipos locales**, no un producto publicado ni una plataforma con cuentas reales. Este repositorio aún no contiene ese prototipo ni backend.

## Dirección y trabajo
El fundador ejerce como CEO y director creativo, aprueba cambios importantes y conserva las cuentas de infraestructura. Agentes de IA pueden preparar código, documentación y propuestas mediante ramas y pull requests; el código de terceros debe pasar controles antes de integrarse.

## Próximos objetivos
1. Incorporar una versión del prototipo aprobada por el fundador.
2. Definir arquitectura web/PWA y base de datos.
3. Crear autenticación real y perfiles profesionales.
4. Proteger datos personales, teléfonos y ubicaciones.
5. Probar con usuarios de Huehuetenango antes de una publicación general.
